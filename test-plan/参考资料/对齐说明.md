## 3 与外部《知识库（RAG）测试完整指南》的吸收说明

参考《知识库（RAG）测试完整指南》（26 页），取舍如下：

**已吸收**：上传成功 ≠ 解析成功 ≠ 切片正确 ≠ 入库正确的核心认知；灰盒 context 验证与获取途径；问题集 9 类分类；context / answer 组合的根因定性三法；配置项测试及其"只改界面不生效"的坑；删除 / 更新后切片与向量清理的高频缺陷；权限问题集需分角色执行、且不能只看前端隐藏；出处定位要求；"素材先行"的顺序约束。

**已改造**：原文档"跨模态"（图文检索）在本项目仅当库内含绿屏画面 / 系统截图 / 流程图时适用；原文档"媒资时间戳准确率"无对应指标，替换为"出处定位率"；"新旧制度混淆"改造为"旧版 / 废止资料误召回"（结合分代数据集）；银行域表格切片风险改造为大机源码结构与定宽格式风险。

**未采用**：媒资知识库相关的时间戳 / 关键帧 / 音视频内容；芯片手册场景的勘误优先级规则；RAGAS 规模化自动评测（本项目缺标准答案，先手工跑通再考虑，图查询部分例外可优先自动化）。
